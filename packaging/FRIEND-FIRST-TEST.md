# ModAgent Pro 1.0 首次外部测试

## 安装

1. 运行 `ModAgent-Pro-Setup-1.0.0.exe`。
2. Windows 若显示“未知发布者”，请确认文件名和开发者提供的 SHA-256 后再选择继续。
3. 首次启动不会携带开发者的 API Key、聊天记录、壁纸、Mod、快照或下载文件。

## 首次配置

测试者需要使用自己的账号和密钥：

- Nexus Mods API Key
- Tavily Search API Key
- DeepSeek API Key

目前 1.0 版界面和默认提示面向中文用户，LLM 仅正式支持 DeepSeek 兼容接口。

## 建议测试流程

1. 填写三项 API Key，关闭并重新启动一次，确认仍显示“已设置”。
2. 选择或扫描一个已安装的 Steam 游戏。
3. 先让 ModAgent 搜索一个普通 Mod，只查看推荐，不安装。
4. 再下载并安装一个体积较小、近期更新且安装说明明确的 Mod。
5. 检查 Mod 管理、禁用/启用、快照创建和快照回滚。
6. 测试 Mod 管理页的“投放文件夹”“Mod 文件夹”“工具目录”按钮。

## 反馈时请提供

- 游戏名称
- 做了什么操作
- 预期结果与实际结果
- 错误截图
- 设置页是否显示三项密钥均已设置

请勿发送 API Key。需要诊断时优先使用应用内生成的脱敏诊断包。
