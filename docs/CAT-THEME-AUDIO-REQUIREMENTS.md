# ModAgent Pro「猫咪夜航」主题音效需求表

## 1. 总体声音方向

- 关键词：月夜、柔软、清脆、轻机械、猫咪陪伴感。
- 主体音色：短促木质敲击、软铃、玻璃星光、布料摩擦、低音量呼噜。
- 猫叫只用于少数关键反馈，不应每次点击都“喵”，避免长时间使用产生疲劳。
- 禁止使用尖锐高频、夸张卡通音、长混响和突发大音量。
- 所有素材必须原创或具有明确商业使用权，并保存来源及授权记录。

## 2. 交付技术规格

| 项目 | 要求 |
|---|---|
| 母带格式 | WAV，48 kHz，24-bit |
| 应用格式 | MP3 192 kbps 或 OGG Vorbis Q6 以上 |
| 声道 | UI 点击可单声道；空间类反馈使用立体声 |
| 峰值 | 不高于 -3 dBFS |
| 综合响度 | 短 UI 音效约 -20 至 -16 LUFS；警告音可到 -15 LUFS |
| 首帧延迟 | 20 ms 以内，文件头不得保留无意义静音 |
| 尾音 | 普通反馈 0.6 秒以内；大型完成反馈 1.4 秒以内 |
| 循环 | 仅扫描/等待类允许循环，必须无缝 |
| 每项变体 | 高频操作至少 3 个轻微变体，随机播放避免机械重复 |

## 4. 猫叫使用规则

- 普通点击、悬停、输入和滚动绝不播放猫叫。
- 回复完成默认不播放猫叫，只使用轻铃和猫爪声。
- 猫叫仅作为成功事件彩蛋，触发概率建议 3%–5%，且 10 分钟内最多一次。
- 错误、警告、删除和网络故障禁止使用受惊、痛苦或尖锐猫叫。
- 设置中应允许单独关闭“猫叫彩蛋”，不影响其他猫咪主题音效。

## 5. 验收方式

1. 连续点击同一按钮 20 次，不应刺耳、削波或产生明显听觉疲劳。
2. Agent 连续完成 10 次回复，提示音不能遮挡其他应用音频。
3. 警告与普通通知必须在盲听时明显可区分。
4. 在系统音量 20%、50%、100% 下分别检查，音效均不得突然爆音。
5. 每个事件都能被现有“编辑音量”滑块单独调节至 0%–100%。
6. 关闭主题或切换主题后，不应继续播放猫咪主题专属音频。
