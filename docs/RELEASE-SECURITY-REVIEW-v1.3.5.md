# ModAgent v1.3.5 发行安全审查

审查日期：2026-07-30

## 结论

v1.3.5 可作为普通版与 P 版共同安全核心的稳定锚点。普通版公开发布；P 安装包与 P 专属资源仅通过私有会员渠道分发。

## 已实施的安全边界

- 普通版构建会拒绝 P 主题、音效、图标和许可证公钥等 P 专属资源。
- Mod 文件写入、删除、快照和清理操作受游戏根目录与 ModAgent 标记目录约束。
- 来源歧义、相似名称和详情证据不足时停止自动覆盖。
- 不认识的安装布局先读取包内 README/INSTALL，再参考来源页教程；没有可靠证据时回滚并请求人工确认。
- 下载重试有上限；404 等永久错误立即失败；登录、成人确认和人机验证单独标识。
- 成功安装后清理临时下载，失败时保留有限诊断信息。
- 安装前创建安全快照，安装事务失败时尝试回滚。
- P 授权失败或到期只影响 P 专属表现层，不阻断核心 Mod 管理，也不会删除用户数据。

## 已知风险

1. 安装包未做 Windows 商业代码签名，SmartScreen 可能警告。
2. 第三方 Mod 页面、下载文件和兼容性不受 ModAgent 控制。
3. 本地离线 P 授权属于“君子锁”，不能保证绝对防破解或远程撤销。
4. 用户自备 API Key 的账号安全仍取决于服务商和本机安全。
5. README/来源页驱动的通用安装只在证据充分时执行；证据不足会降低自动化程度，但这是安全设计。
