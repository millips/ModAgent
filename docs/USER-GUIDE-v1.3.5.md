# ModAgent v1.3.5 使用教程

## 安装

- 普通版：运行 `ModAgent-Setup-1.3.5.exe`。
- P 版：运行 `ModAgent-P-Setup-1.3.5.exe`。
- 两个版本都支持覆盖安装。标准卸载默认保留 `.modagent` 用户数据。
- 当前安装包未做商业代码签名。运行前请核对发布页提供的 SHA256。

## 首次配置

首次启动至少需要一个可用的大模型 API：

1. 选择 DeepSeek、OpenAI/GPT 或兼容 OpenAI API 的服务。
2. 填写 API Key 并选择模型。
3. Nexus Mods API Key 与搜索 API 可以暂时留空；留空可能降低搜索覆盖率或下载自动化能力。
4. Nexus 网页下载需要浏览器登录时，请保持 ModAgent 打开的浏览器窗口可用。

## 导入游戏与管理 Mod

- 优先使用“重新扫描游戏”，未识别时再使用“手动导入游戏”并选择游戏根目录。
- 同一下载包内的变体和组件按一个 Mod 包管理，避免把一个服装包拆成大量无法独立更新的条目。
- ModAgent 自己完成下载与安装时会记录稳定来源，安装完成后自动刷新 Mod 列表。
- 来源存在歧义时必须由用户确认，不会仅凭相似名称覆盖本地文件。

## 推荐、核验与安装

推荐清单会展示中文简介、原名、来源、版本、依赖、风险和详情核验状态。前置依赖应排在目标 Mod 前面。

安装顺序为：

1. 确认目标；
2. 补齐详情及必要依赖；
3. 创建安全快照；
4. 下载；
5. 安装前核验；
6. 安装并刷新列表。

若已知游戏特化规则无法识别目录，ModAgent 会继续读取压缩包中的 README/INSTALL 等说明，并结合来源页安装教程生成证据化安装建议。没有可靠证据时会停止，不会猜测路径。

## 下载与缓存

- 下载文件先进入 `.modagent` 临时缓存。
- 成功安装后会清理本轮临时压缩包；失败时可保留必要诊断信息。
- 404 等永久错误不会反复重试；登录、成人确认或人机验证会明确提示用户处理。
- 点击停止后会终止当前任务及其后续重试，新消息不会继续被旧任务占用。

## 快照、日志与卸载

- 大批量修改前建议创建快照。快照是 Mod 文件回滚点，不替代游戏存档备份。
- 设置页可以打开日志、配置和缓存目录，并导出诊断。
- 彻底清理请使用 `ModAgent-Cleanup-1.3.5.exe`。清理器只处理经过标记验证的 ModAgent 目录；选择清除用户数据后不可恢复。
