# ModAgent v1.5.0 发行安全审查

审查日期：2026-08-01

## 结论

v1.5.0 可作为普通版与 P 版共同的正式发布版本。两版共用搜索、核验、安装计划、本地 Mod 管理、快照和官方合集导入能力；P 版额外提供 P 视觉权益及 P Share 投稿能力。

## v1.5 社区合集安全边界

- 官方合集 JSON 只保存游戏、对齐 Mod、上游 URL、版本、依赖、状态、排序及作者警告；不写入 API Key、Cookie、账号、绝对游戏路径、本地文件或受版权保护的 Mod 内容。
- 官方代码只能在审核员核验后写入 ModAgent-Share 官方仓库与 `index.json`。导入端只接受已发布代码。
- 导入动作只预览和核验；安装仍须由用户生成计划并确认。
- 官方审核拒绝包含侵权转载、限制级/违法内容、隐私或密钥、恶意指令、误导性来源的投稿。私下 JSON 分享不属于官方目录。
- ModAgent 只导航至作者和平台的上游页面，不重新托管第三方 Mod 文件。

## 已实施的本地安全边界

- 文件写入、卸载、快照与清理受游戏根目录或 ModAgent 已标记目录约束。
- 来源歧义、相似名称和详情证据不足时停止自动覆盖。
- 不认识的安装布局优先读取 README/INSTALL 和上游说明；证据不足时要求用户确认。
- 404 等永久错误不会无限重试；登录、人机验证和成人确认会作为独立状态提示。
- 成功安装后清理临时下载缓存；批量操作前可创建快照，失败时尝试事务回滚。
- 普通版构建隔离 P 的主题、音效、图标和许可证公钥；P 构建携带独立 P 身份与合法资源集。

## 已知限制

1. 安装包尚未进行商业代码签名，Windows SmartScreen 可能提醒未知发布者。
2. 第三方 Mod 页、下载文件、版本和兼容性不由 ModAgent 控制；详情核验不等于游戏内效果保证。
3. P 授权目前为离线签名的君子锁，不保证绝对防破解、远程撤销或设备数限制。
4. 用户自行填写的 API Key 的安全性仍取决于服务商和本机环境。
