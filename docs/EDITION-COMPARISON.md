# ModAgent v1.3 普通版与 P 功能矩阵

本文以 v1.3.0 稳定版候选的实际代码边界为准。没有落地或没有经过发行验证的能力，不列为 Pro 已交付功能。

## 定位

- **普通版（ModAgent）**：开放的本地 AI Mod 管理完整闭环，包含结构化推荐、依赖核验、安装计划和配置补丁。
- **P 版（ModAgent P）**：核心能力与普通版相同，只增加主题、音效、视觉动效/反馈核心和专属身份标识。

普通版和 P 版使用独立的应用身份、更新通道、用户数据目录和法律资源。两者都不会绕过第三方网站的登录、人机验证、付费限制或作者许可。

## 当前不应宣传为已交付

- **内置托管大模型**：当前两版均需要用户自己的 LLM API Key。
- **联网授权与设备撤销**：v1.3.0 使用 3 天试用和 60 天离线签名兑换码；联网授权、设备上限和远程撤销属于后续阶段。
- **绝对防破解**：客户端软件无法保证绝对不可破解，只能通过签名、服务端授权、最小化客户端秘密和风控提高成本。
- **所有游戏全自动兼容**：多源搜索是开放适配，安装器仍只对已实现规则提供确定性落位；未知游戏必须显示通用规则风险。
- **第三方 Mod 兼容性保证**：详情核验只证明页面信息已取得，不代表目标游戏版本和 Mod 组合已经实机通过。

## P 首发授权边界

- P 安装包首次启动提供 3 天试用。
- 爱发电发放离线签名兑换码，每码首发有效 60 天。
- 兑换状态保存到本机 `license.dat`，并由 Windows 加密存储保护。
- 到期只锁定四类 P 表现层权益；搜索、核验、安装、更新、卸载、快照和用户数据继续可用。
- 客户端只内置验签公钥，签发私钥不进入仓库或发行包。
- 本地桌面软件无法保证绝对不可破解；后续可在不改变 UI 的前提下接入 Cloudflare 联网验证。

## 发行与迁移

v1.3.0 是稳定通道版本。此前 v1.10.x 仅用于独立 Beta 通道测试；由于 SemVer 中 `1.10.x` 高于 `1.3.0`，Beta 用户迁移到稳定版时应使用稳定安装包，不依赖 Beta 自动更新完成“降级”。Beta 和 Stable 的数据目录保持隔离。
