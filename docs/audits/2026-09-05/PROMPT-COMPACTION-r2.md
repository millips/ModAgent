# 提示词治理 r2（2026-09-06）

范围：用户要求优先精简提示词，暂缓搜索系统重构。本批不调整模型、搜索排序、来源适配器、工具权限矩阵或真实安装事务。

## 实际变化

- 原 prompts.py 保留为 legacy_prompts.py；原 v2 提示词保留为 orchestration/legacy_prompting.py，均仅供离线对照。default_prompt.md 保留但不再进入活动提示词链路。
- prompts.py 是共享核心入口；orchestration/prompting.py 管理核心、11 类模式、条件性游戏规则、有限风格偏好、上下文数据与体积统计。
- 普通/流式入口都使用短核心。兼容 off/shadow 共用相同提示词与工具集合；on 的任务工具门禁继续生效。没有借提示词重构打开新的写权限。
- 移除旧“每轮必须工具调用或问题结尾”“缓存/下载返回就立即安装”等强制推进语义；必要确认、来源依据、失败/等待状态、回滚预览、安装后配置验证保留。
- 构建提示词不调用来源探测或已装清单查询，状态通过工具按需取得；因此组装阶段不会为普通问答先做网络探测。
- 用户选择 JSON、暂停目标及重新生成摘要移到上下文数据消息；选择文件/变体 ID 保留，不写回为用户新指令。数据仍有体积，未从费用统计中隐去。
- 重新生成摘要不再被系统宣告为已生效。on 的只读任务不注入“继续下载”的冲突指令。
- 自定义 prompt.md 不改写、不删除，只识别有限整行的语气/长度偏好，无法通过自由文本覆盖运行规则。其他称呼/推荐偏好等尚未形成完整结构化设置，暂不支持。
- 每次实际模型请求记录 prompt_metrics 的字符数/工具数，不记录用户文字、路径、密钥或来源正文；这些是字符数，不是 tokenizer/计费数据。

组织参考：[OpenAI 官方 Prompt engineering 文档](https://developers.openai.com/api/docs/guides/prompt-engineering#message-formatting-with-markdown-and-xml) 的身份、规则与上下文分层。没有迁移到文档示例中的模型，也没有运行真实模型请求。

## 验收

- 最终 All 106 regression files passed，逐文件独立进程；不等价于 106 条真实模型问答。
- 三项旧断言按新契约更新：不再要求提示词预探测来源、不透传旧自定义执行模板、历史操作不放在系统指令中。来源实际搜索和副作用测试仍保留。

本批没有验证真实模型准确率、真实网络搜索、真人桌面交互和真实游戏安装；也没有完成服务端计划授权、完整任务恢复与文件事务取消。不能据长度下降宣称这些问题已修复。
