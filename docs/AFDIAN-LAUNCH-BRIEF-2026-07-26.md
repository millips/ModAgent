## 3. 产品定位

ModAgent 是一个 AI 驱动的开放式多源 Mod 管理器。

核心定位：

- 用户用中文描述需求，工具帮助搜索、核验、推荐、下载、安装、更新、卸载 Mod。
- 主打多源开放适配，不绑定单一平台。
- 不绕过第三方网站登录、人机验证、作者权限、付费限制或下载规则。
- 普通版保留完整核心工作流；Pro 更偏向高级体验、主题、音效、通知、优先测试与支持。

建议对外一句话：

ModAgent 是一个由 AI 驱动的 Mod 管理助手，帮助玩家用自然语言搜索、核验、推荐、安装、更新和管理不同来源的游戏 Mod。

## 4. 普通版与 Pro 的区分

普通版必须保留完整可用的核心闭环，否则容易伤害口碑。

普通版包含：

- 自然语言对话与需求拆解
- 用户自备 LLM API Key
- 游戏目录检测与手动导入
- 本地 Mod 扫描
- 多源搜索，包括 Nexus、Steam Workshop、Thunderstore、GitHub、GameBanana 等
- 网页详情核验
- 智能推荐决策表
- 候选 Mod 功能简介、版本、活跃度、依赖与风险展示
- 前置依赖置顶与标明
- 推荐结果联动安装计划
- 推荐选择和执行阶段跨会话恢复
- 结构化配置补丁核验，覆盖 JSON、INI、CFG、TXT、XML
- 下载、安装、卸载、启用、禁用
- 快照、影响预览与回滚
- 诊断导出与隐私脱敏
- 朴素版/设计版布局切换

Pro 包含：

- 普通版全部能力
- Pro 视觉主题
- Pro 专属界面美术资源
- Pro 音效与操作反馈
- Windows 通知与恢复提示
- 优先获得稳定候选版和测试版
- 优先反馈处理
- 会员专属发布说明、测试记录与后续路线预览

当前不要宣传为已交付：

- 内置托管大模型
- 已完成服务端订阅验证
- 绝对防破解
- 所有游戏全自动兼容
- 所有第三方 Mod 兼容性保证
- 不需要第三方站点登录或验证

## 5. 爱发电档位建议

用户已接受当前建议档位：

| 档位 | 价格 | 定位 | 权益 |
| --- | ---: | --- | --- |
| 开发支持者 | 5 元/月 | 低门槛支持项目 | 开发日志、路线投票、感谢名单、普通版更新提醒 |
| Pro 先行体验 | 18 元/月 | 推荐主档位 | 获得当前有效期内的 Pro 下载入口、Pro 主题/音效/通知、优先测试稳定候选版、优先反馈 |
| 核心共创成员 | 38 元/月 | 深度共创 | 包含 Pro 档权益、优先测试、新功能投票权重、月度问答、核心共创鸣谢 |

爱发电赞助周期按平台规则理解为约 31 天有效。当前建议的诚实规则是：

在发电有效期内，用户可以获取最新 Pro 下载链接和会员内容。到期后，已经下载的旧版本不会被主动锁死或删除，但用户不再获得新的 Pro 包、私有链接和会员内容。

这条规则非常重要，因为当前 Pro 还没有接入真正的 entitlement 授权服务。如果现在就承诺“到期自动停用 Pro”，代码层面还做不到；如果承诺“永久更新”，后续商业化会被绑死。

## 6. 蓝奏云发放建议

建议蓝奏云分成两个入口：

普通版公开入口：

- 文件夹：`ModAgent 普通版`
- 内容：`ModAgent-Setup-1.3.0.exe`、普通版便携包、SHA256
- 链接可放 GitHub Release、爱发电公开文章、B 站简介、自媒体评论区

Pro 私有入口：

- 文件夹：`ModAgent Pro 私有发布/v1.3.0`
- 内容：`ModAgent-Pro-Setup-1.3.0.exe`、SHA256、简短安装说明
- 链接和密码只放在爱发电 Pro 档付费文章中
- 每个大版本建议更换链接和密码
- 不建议把 Pro 链接放到 GitHub Release

现实风险：

这种方式只能降低泄露概率，不能真正阻止复制传播。只要用户拿到 Pro exe，就可以转发给别人。真正的防泄露需要服务端授权、短期下载链接、设备激活和能力边界校验。

## 7. 当前 Pro 订阅安全策略

短期最快方案：

- 爱发电收款
- 蓝奏云私有链接发放 Pro
- 到期后停止给新链接
- 公开说明当前是“先行体验支持版”
- 不承诺强 DRM

中期稳定方案：

- 接入 Lemon Squeezy 或类似成熟支付/许可系统
- 自建最小授权服务
- 支持设备激活，默认 2 台设备
- 服务端签发短期 entitlement token
- 客户端只保存公钥，不保存签发私钥
- Electron 使用 `safeStorage` / Windows DPAPI 保存本地凭据
- 在线 token 有效期 72 小时
- 最近成功验证后给 7 天离线宽限

长期抗破解方案：

- 下载链接改为短期签名 URL
- 更新清单签名
- Pro 能力在 Electron、后端和服务端多层校验
- 支持用户、设备、token、版本撤销
- 记录异常下载频率和设备异常
- 高价值在线能力放服务端校验

原则：

不要把“构建版本是 Pro”当成“用户已订阅”。当前 `subscription` 构建身份只区分包和资源，不等于真实授权。

## 11. 当前已知产品风险

搜索与推荐：

- 搜索摘要不能等于详情核验，必须点进详情页核验后再显示“详情已核验”。
- 推荐 Mod 必须有足够介绍，否则用户无法判断。
- 前置依赖必须置顶，并明确“为什么需要”。
- 不可安装项要说明原因，并给出下一步：重新核验、打开来源页、保留目标、手动导入。

安装路径：

- Stardew Valley 使用 SMAPI，应安装到 `Mods/`，不能错误安装到 `BepInEx/plugins/`。
- 不同游戏需要逐步积累专用安装规则。
- 未知游戏应显示通用安装风险，不应假装完全适配。

数据与清理：

- 下载临时目录应在安装完成后自动清理。
- 快照如果使用硬链接或增量策略，体积一般很小，但 UI 需要显示真实占用和可清理建议。
- 卸载器应清理安装目录残留，并提供可选清理 `.modagent` 数据目录的独立工具。

UI：

- 小窗模式必须可完整操作。
- 设计版布局应使用黄金比例/白银比例的宽度分配，但不能吞图标、吞文字、推高顶部或造成底部留白。
- Pro 美术可以大胆，但操作密度和可读性不能牺牲。

  - Tavily 可选
  - Brave Search 可作为热门补充
  - Nexus API 可选
  - 没有搜索 API 时仍可通过浏览器/CDP 和直接链接工作

- 短期签名下载链接

## 13. 最适合现在采用的发布口径

推荐口径：

先把 v1.3.0 当作“稳定准备发行版”公开发布。普通版免费开放，Pro 作为爱发电先行体验包私有发放。当前 Pro 的主要价值是更好的视觉、音效、通知、先行测试与优先反馈，不把它宣传成强授权、绝对防泄露或内置托管大模型版本。

一句话总结：

现在最稳的路线不是先追求复杂 DRM，而是诚实发布、控制 Pro 私有分发、快速收集真实用户反馈，同时把服务端授权作为下一阶段工程目标。
