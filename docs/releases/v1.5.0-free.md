# ModAgent v1.5.0（普通版）

v1.5.0 是一次面向“可复现 Mod 配置”的功能发布：除了搜索、核验、安装计划与本地管理，ModAgent 现在可以读取经过官方审核的社区合集代码，在执行前把本机已装项、缺失依赖、冲突和风险集中展示出来。

## 本次新增

- **官方社区合集导入**：输入 `ma-游戏-六码` 后，从 ModAgent-Share 官方仓库读取已发布 JSON；先预览和核验，再由用户决定是否生成安装计划。
- **导入前本机核验**：逐项检查已安装状态、来源、版本、依赖、冲突与重复项；基础运行环境会单独提示，不会被误当成普通 Mod 重复安装。
- **配置可复现**：官方合集保存游戏、已对齐 Mod、上游页面、版本、依赖、启用状态、排序和必要警告；不含 API Key、Cookie、账号、游戏路径或本地文件内容。
- **创作者友好入口**：已对齐 Mod 可一键打开其官方来源页面，保留作者原始下载量与页面流量。

## 普通版包含

- AI 对话式搜索、候选结果核验、安装计划与人工确认；
- 游戏扫描、Mod 管理、更新检查、启用/禁用、卸载、快照和诊断导出；
- 官方已审核合集的导入、预览与本机核验。

## 不包含

- P 专属主题、音效、视觉反馈和 P 身份标识；
- P Share 创作者投稿功能。

## 使用与安全说明

- ModAgent 不绕过第三方站点的登录、人机验证、付费或作者权限；出现此类页面时需用户自行完成平台要求。
- 导入合集只会生成预览与安装计划，不会直接自动安装。
- 安装包尚未进行商业代码签名。下载后请使用 `SHA256SUMS.txt` 核验文件完整性。
