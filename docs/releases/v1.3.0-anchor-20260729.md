# ModAgent v1.3.0 发布锚点（2026-07-29）

这是 v1.3.0 在多轮公测打磨后的重新发布锚点，普通版与 P 版使用同一套安全核心。

## 本轮重点

- 将同一下载包内的服装变体、组件与资源统一按一个 Mod 包管理，避免把一个包误计为多个可独立更新/卸载的 Mod。
- 扫描和导入阶段识别已归属包的文件子集，防止同一物理文件被重复登记。
- 修复快照列表与删除使用不同游戏身份导致的“跨游戏拒绝删除”。
- 收紧 GitHub 搜索相关性；游戏归属证据不足的仓库不再进入可安装候选。
- 多源搜索记录各来源已搜索、未收录、未配置、失败或跳过状态，不再把“没搜”说成“没有”。
- BepInEx 常见拼写误差只在明确的加载器语境中纠正，避免把普通搜索词误改成依赖请求。
- 同名来源存在高相似竞争项目时停止自动绑定，要求用户确认稳定来源 ID。

## 同步改进

- 推荐、依赖补齐、安装计划和安装前核验流程继续收紧，已安装依赖不再重复加入。
- 下载停止后终止旧任务与重试，后续新消息不会继续被中断的旧任务。
- 下载失败按错误类型反馈，404 等永久错误不再无意义重试。
- Mod 管理页增加包级中文简介、绑定/对账进度、取消和重复来源安全提示。

## 校验

- Python 回归：84 个回归文件全部通过。
- Electron 身份、构建身份、更新、卸载、P License、快捷回复、推荐恢复和运行诊断测试全部通过。
- 前端生产构建及商业音效/发布文案校验通过。

> GitHub Release 仅公开普通版。P 版安装包和 P 专属资源继续通过私有会员渠道分发。
