# ModAgent v1.10 测试候选版

状态：朋友测试阶段，尚未正式发布。

## 本轮重点

- 新增 Xbox / Microsoft Store 游戏扫描与手动重新扫描入口。
- 推荐清单默认最多显示 10 项，并可在设置中调整为 2–20 项。
- 修复推荐清单刷新后位置漂移、窄窗口折叠布局和下载摘要不完整问题。
- 改进多来源推荐详情、已安装 Mod 去重和依赖信息展示。
- 改进长任务进度文案，使用阶段状态与动态提示降低等待焦虑。
- 完善下载缓存生命周期，成功安装、工具解压及重复项会清理受管缓存。
- 新增星露谷物语 / SMAPI 特化：
  - 区分文件安装、Steam 启动参数、首次运行和 Mod 实际加载状态；
  - 输出可直接复制的完整 Steam 启动命令；
  - 读取 `SMAPI-latest.txt` 验证加载结果；
  - 写入前检查 `manifest.json` 中的必需前置和最低版本。
- 加强诊断信息脱敏、版本资产隔离和发行前自动检查。

## 测试重点

1. 普通版与 Pro 版都能正常启动并识别版本为 v1.10。
2. Steam、Epic、Xbox/Microsoft Store 游戏扫描结果准确，点击“重新扫描游戏”能发现新安装游戏。
3. 已安装 Mod 不再被推荐或重复下载。
4. 星露谷物语安装 SMAPI 后，ModAgent 能明确提示 Steam 启动参数，并在首次运行后识别已加载 Mod。
5. 缺少 Content Patcher、Farm Type Manager 等必需前置时，安装会在写盘前停止。
6. 推荐、下载、安装、快照、回滚及更新流程没有出现答非所问或虚假完成。

发现问题时请附上：当前游戏、操作步骤、界面截图，以及设置页导出的脱敏诊断信息。
