# ModAgent v1.3.0（普通版）

ModAgent 普通版提供开放的本地 AI Mod 管理核心：多源搜索与详情核验、游戏识别、本地 Mod 扫描、下载和安装确认、统一管理、更新检查、快照及回滚。

## v1.3.0 更新

- 改进 Steam 自定义库和多游戏安装实例识别。
- 推荐结果提供更完整的中文说明、来源、版本、依赖和风险信息。
- 提供结构化推荐决策表、智能预选、最终勾选与安装计划联动。
- 前置依赖置顶并标明被谁需要；缺失或未核验依赖不会被静默跳过。
- 暂不可安装候选可以保留为待处理目标，并继续核验、打开来源页或转为手动导入。
- 推荐选择和执行阶段可以随会话恢复。
- 可在设置中切换朴素布局与黄金比例非对称设计布局；桌面原生菜单栏默认隐藏。
- 支持 JSON、INI、CFG、TXT、XML 配置补丁。
- 更新对象存在歧义时停止猜测，等待用户确认稳定来源。
- Stardew Valley/SMAPI Mod 强制安装到正确的 `Mods/` 结构。
- 加强重复安装预检、失败回滚和诊断记录。
- 修复卸载后自定义安装目录残留。

## 与 Pro 的边界

普通版不包含 Pro 的订阅主题、专有视觉/音频资源、氛围打光、反馈校准和 Windows 回复通知体验。结构化推荐、跨会话恢复、配置补丁、搜索、下载、安装、管理、更新检查和快照回滚不因普通版身份而移除。

两版目前都需要用户配置自己的模型和搜索服务 API Key。完整矩阵见仓库中的 `docs/EDITION-COMPARISON.md`。
