# ModAgent v1.3.0（普通版）

ModAgent 普通版提供开放的本地 AI Mod 管理核心：多源搜索与详情核验、游戏识别、本地 Mod 扫描、下载和安装确认、统一管理、更新检查、快照及回滚。

## v1.3.0 更新

- 改进 Steam 自定义库和多游戏安装实例识别。
- 推荐结果提供更完整的中文说明、来源、版本、依赖和风险信息。
- 更新对象存在歧义时停止猜测，等待用户确认稳定来源。
- Stardew Valley/SMAPI Mod 强制安装到正确的 `Mods/` 结构。
- 加强重复安装预检、失败回滚和诊断记录。
- 修复卸载后自定义安装目录残留。

## 与 Pro 的边界

普通版不包含 Pro 的结构化推荐勾选工作台、推荐 UI 状态持久化、配置文件智能补丁、订阅主题、专有视觉/音频资源和反馈校准体验。搜索、下载、安装、管理、更新检查和快照回滚不因普通版身份而移除。

两版目前都需要用户配置自己的模型和搜索服务 API Key。完整矩阵见仓库中的 `docs/EDITION-COMPARISON.md`。
