# ModAgent v1.3.5（普通版）

v1.3.5 是 2026-07-30 的大型稳定锚点，集中收束安装证据链和 Nexus 多文件下载流程。

## 主要改进

- 新增 Street Fighter 6 的 `natives`、REFramework 安装路径识别。
- 未知布局不再盲猜目录：优先读取 README/INSTALL，再结合来源页教程给出可审计的安装方案。
- Nexus 多文件页面按稳定 `file_id` 选择，多个变体无法确认时停止并请求选择。
- 页面流程、重试和人工验证状态进一步区分，永久错误不再无意义循环。
- 批量安装继续执行依赖核验、快照、事务回滚与临时缓存清理。

## 发布说明

- 本 Release 仅提供普通版。
- P 版安装包、P 专属主题、音效和图标不进入公开 GitHub Release。
- 安装包尚未商业签名；请核对 `SHA256SUMS.txt`。
