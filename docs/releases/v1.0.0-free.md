# ModAgent v1.0.0（普通版）

ModAgent 是一款面向 Windows 的本地 AI Mod 管理器。它把游戏识别、Mod 搜索与分析、安装前确认、本地管理和快照回滚放进同一个桌面界面，帮助玩家减少在网页、压缩包和游戏目录之间反复切换的成本。

![ModAgent 普通版对话与状态总览](../assets/promo/v1.0.0/01-chat-overview.png)

## 本版包含

- AI 对话式 Mod 搜索与方案分析
- 本机游戏自动识别与手动导入
- 已安装 Mod 扫描、启用、禁用和卸载管理
- 安装前确认与关键操作提示
- 本地快照、变更预览和回滚
- Nexus Mods 等来源的网页辅助流程
- 本地桌面应用；用户自行配置所需的 API Key

## 下载

- 推荐大多数用户使用 `ModAgent-Setup-1.0.0.exe`
- 需要免安装运行时使用 `ModAgent-Portable-1.0.0.zip`
- 可使用 `SHA256SUMS.txt` 校验下载文件完整性

## 使用前须知

1. 当前仅提供 Windows x64 构建。
2. 首次启动需要按界面提示配置 Nexus Mods、搜索服务和大模型 API Key。
3. Nexus Mods 可能触发登录、人机验证或 “Slow download” 页面。遇到验证时，需要用户在浏览器完成验证或点击下载；ModAgent 会继续接管后续可自动完成的步骤。
4. 安装、卸载和回滚都会修改本地文件。执行前请核对目标游戏与文件清单，并保留重要存档的独立备份。
5. Mod 及其页面内容来自第三方，版权、兼容性和可用性由相应作者及平台负责。

## 普通版与 Pro 的边界

普通版包含核心的搜索、分析、管理与快照能力。Pro 的交互式推荐勾选表、订阅视觉主题与反馈特效、面向订阅用户的增强交互不包含在此 GitHub 普通版中。
