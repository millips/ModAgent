# ModAgent v1.3.5 大型发布锚点（2026-07-30）

该锚点对应普通版与 P 版共用的安装、下载、安全和诊断核心。

## 锚点内容

- 通用安装从“猜测目录”升级为“游戏特化规则 → 包内说明 → 来源页教程 → LLM 证据判断”。
- 对无可靠安装证据的包安全停止并回滚，不以重试掩盖路径错误。
- Nexus 文件选择使用稳定文件 ID，避免多变体页面选错文件或长时间卡死。
- 下载页面的永久失败、人工门禁与暂时网络问题分别处理并设置有限重试。
- 普通版与 P 版采用同一代码提交构建；P 专属资产继续保持私有。
