# ModAgent v1.3.0 稳定版候选

v1.3.0 将此前多轮公测验证过的多源推荐、详情核验、安装安全和诊断能力收束到稳定发行基线。

## 本版重点

- 多源 Mod 搜索、详情核验和可读的中文推荐说明。
- 本地 Mod 清单优先，减少重复下载和错误更新对象。
- 相似 Nexus 项目不再猜测绑定；歧义时展示完整证据并等待确认。
- Stardew Valley 使用 SMAPI `Mods/` 专项安装，拒绝错误落入 `BepInEx/plugins/`。
- D 盘及自定义 Steam 库检测、多个游戏安装实例隔离。
- 安装、更新、卸载、快照和回滚的确认与失败恢复。
- 完整诊断导出、UTF-8 日志和敏感信息脱敏。
- 卸载时精确终止当前安装目录的后端并删除安装残留，不影响其他版本。
- 普通版与 P 共用结构化推荐决策表、跨会话恢复和配置补丁。
- 前置依赖在推荐和安装计划中置顶，标明被谁需要和核验状态。
- 暂不可安装候选不再只有灰色复选框，可保留目标并继续核验、打开来源页或转为手动导入。
- 两版均可在设置中切换朴素布局与黄金比例非对称设计布局；桌面原生菜单栏默认隐藏。

## 普通版与 P

普通版包含完整的搜索、核验、结构化选择、依赖优先计划、下载、安装、配置补丁、管理、更新检查和快照回滚核心。

ModAgent P 额外提供：

- P 专属主题；
- P 专属音效；
- P 视觉动效与反馈核心；
- P 专属图标和身份标识。

P 首发提供 3 天试用和 60 天离线签名兑换码；到期只锁定上述四类权益。详细边界见 [普通版与 P 功能矩阵](../EDITION-COMPARISON.md)。

## 迁移说明

此前 v1.10.x 属于独立 Beta 通道。因为 SemVer 中 `1.10.x` 高于 `1.3.0`，Beta 测试用户迁移到稳定版时需要直接运行稳定版安装包；不要依赖 Beta 自动更新完成版本切换。Beta 与 Stable 数据目录相互隔离。
