# ModAgent v1.5.1（普通版）

v1.5.1 是 v1.5 社区合集功能的稳定修复版。

## 修复与改进

- 正确识别已安装的 BepInEx、SMAPI、MelonLoader 等基础运行环境。
- 官方合集导入的安装计划门禁更准确：缺失依赖先补齐，满足后再生成计划。
- Thunderstore 优先使用已知游戏社区，并加入一次受控重试和本地目录回退。
- 分享者主页可读取并复制已发布投稿的官方分享六码。
- GitHub 默认源码分支已更新为当前 v1.5 稳定源码，并移除误上传的开发器配置文件。

## 发布文件

- `ModAgent-Setup-1.5.1.exe`
- `ModAgent-Portable-1.5.1.zip`
- `ModAgent-Cleanup-1.5.1.exe`
- `SHA256SUMS.txt`

官方合集导入只会预览、核验并生成安装计划，最终安装始终由用户确认。
