# ModAgent v1.5.0 使用教程

## 安装

- 普通版运行 `ModAgent-Setup-1.5.0.exe`；P 版运行 `ModAgent-P-Setup-1.5.0.exe`。
- 便携包解压后运行对应 EXE；安装器和便携包不要混放在游戏目录中。
- 覆盖安装会保留 `.modagent` 配置、聊天记录、快照和 P 授权；卸载默认也保留这些数据。
- 当前安装包未进行商业代码签名，运行前请对照发布页的 `SHA256SUMS.txt`。

## 首次配置

1. 填写一个可用的大模型 API。DeepSeek 为推荐默认，也支持 OpenAI 兼容接口。
2. 选择模型。搜索 API 与 Nexus API 均可暂时跳过，之后可在设置补充。
3. 需要 Nexus 网页下载时，请保持 ModAgent 打开的浏览器窗口可用，并自行完成登录或人机验证。

## 日常 Mod 管理

- 先重新扫描游戏；找不到游戏时再手动选择游戏根目录。
- Mod 管理页可执行启用、禁用、卸载、更新检查和来源对齐。来源不确定的项不会被用作可分享来源。
- 安装计划会先列出目标、前置依赖、冲突、安装路径和风险。没有可靠安装证据时，不会猜测目录。
- ModAgent 安装完成后会刷新本机 Mod 列表，并清理本轮已成功使用的临时下载压缩包。

## 导入官方社区合集（v1.5 新增）

1. 在首页点击“导入社区合集”。
2. 输入官方代码，例如 `ma-repo-000002`。
3. 先查看预览：已安装、待核验、缺失来源、依赖和警告。
4. 让对话助手读取该合集并核验本机情况。
5. 没有阻塞依赖时，点击“生成安装计划”；有缺失依赖时先补齐依赖，再生成计划。
6. 最终安装仍需用户确认。

官方合集只读取审核通过的公开 JSON。它不含 API Key、Cookie、账号、游戏路径或本地文件内容。

## P Share 投稿（P 版）

1. 在设置中完成 P 会员验证后，进入 “P Share / 分享者主页”。
2. 在 Mod 管理页选择已对齐来源的 Mod，点击“导出分享配置”。
3. 填写标题、简介和警告，导出 JSON；打开预填 GitHub 投稿页后提交。
4. 回到分享者主页，点击“从剪贴板关联 Issue”以关联刚提交的投稿。
5. 审核状态为“已发布”后，即可使用正式 `ma-游戏-六码` 分享。

私下导出的 JSON 可以自行分享，但不会自动成为官方合集，也不会获得官方代码。

## 快照、日志和清理

- 重要批量操作前创建快照；快照用于 Mod 文件回滚，不替代游戏存档备份。
- 设置中可以打开日志、配置和缓存目录，或导出诊断文件。
- 使用 `ModAgent-Cleanup-1.5.0.exe` 前请先退出 ModAgent。清理器只处理经过标记验证的 ModAgent 目录；选择清除稳定数据后不可恢复。
