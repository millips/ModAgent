# r8 源码改进与验证记录（2026-09-07）

本轮不是桌面发布，没有覆盖 r7a/正式程序，没有操作真实游戏、存档、已装 Mod 或用户密钥。逐字流式未改。

## 已修复

### 卸载真实性与恢复保护

- 删除失败、原件恢复失败、越界记录被阻止时保留管理记录，不再无条件删账并报成功。
- 外部配置清理失败也保留记录和备份；明确部分完成，需重新检查并预览，不自动续跑。
- 正确移除已禁用的 .disabled 文件；启用和禁用文件同时存在时不猜测归属。
- 文件缺失但原件备份存在时恢复原件，不删除唯一备份。
- 原件在目标卷暂存、校验、原子替换；管理记录和外部配置处理完成前不消耗备份。
- 取消后不开始下一文件，已经进入的单文件恢复安全收尾并保留部分结果。
- Steam 退订未确认成功时保留订阅记录；其他 Mod 仍拥有的共享文件不删除。

代码：modagent/installer.py、modagent/tools.py。

### 需求与证据

- 增加不可变 GoalRequirements，保留原文、需要/排除的功能、具体功能、数字数量和收敛限制；匹配、预选、现有搜索收敛判断复用同一解释。
- 标题、作者和标签不能单独证明功能；区分明确不匹配与证据不足，后者不自动勾选。
- 不忽略用户排除的贴图等功能；金币贴图、余额显示不能证明具有金钱修改能力。
- 指定计时器时，只有其他信息功能不算满足；计划中的功能不算当前实现。
- 数字数量约束自动勾选数，保留原有最多四个的自动预选上限。
- 新详情使用新的来源正文核验，不沿用旧生成简介作为证据；不匹配或缺证据时不自动选中。

代码：modagent/recommendation_fit.py、modagent/recommendation_ui.py。

### 隔离完整执行链路

tests/test_r8_uninstall_lifecycle.py 使用本机 HTTP 服务传输真实 ZIP 字节，真实调用下载、安装预检、确认、快照、文件事务、启停和卸载。游戏结构、文件均为临时虚构内容，不启动 EXE。

顺序：下载 → 只读预检 → 确认安装 → 检查文件和数据库 → 检查安装前快照保护原件 → 禁用 → 启用 → 新 Python 进程读取记录且不执行 → 卸载 → 验证原件恢复、新文件消失、记录移除、无关存档字节不变。

另测外部配置清理失败后，用新进程明确重新预览并重试，原件仍完整。这不是全任务调度器的任意检查点恢复。
