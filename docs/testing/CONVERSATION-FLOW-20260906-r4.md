# ModAgent Conversation Flow r4 独立测试包

版本：1.6.0-beta.1；构建标识：conversation-flow-20260906-r4。
继承 r1 安全边界、r2 精简提示词和 r3 共享凭据机制。本包不是 Agent Core v2 全部完成的正式版。

## 打开哪个

- Free/ModAgentBeta-CoreSafety.exe
- P/ModAgentPBeta-CoreSafety.exe

请保留完整 Free/P 文件夹，不要只复制 exe。文件名沿用旧候选包名称，以所在文件夹的 r4 标识区分。
不覆盖现有正式版、r1、r2 或 r3。应用自动更新关闭。
测试配置位于 %APPDATA%/ModAgent-TestProfiles/conversation-flow-20260906-r4/free/data 或 subscription/data。
只共享已绑定地址的加密凭据；会话、Mod 清单和授权隔离。数据隔离不等于游戏目录隔离，写入测试仍应选择模拟游戏目录。

## 本轮修复

1. 普通回答不再整段复制到“已完成”卡。失败、部分完成、等待确认及真实工具结果保留；旧格式重复摘要也兼容去重。
2. “帮我搜搜看”等口语进入只读搜索；同一游戏下最近的“辅助学习的、界面优化的”等补充保留搜索目标。
3. 明确搜索却只得到模型询问偏好时，调度器可补发一次受白名单限制的搜索。没有搜索收据不得标记搜索完成。
4. 聚合来源全部失败记为失败，部分失败记为部分完成；成功但空结果与失败分开。不把来源失败说成没有 Mod。
5. 等待人工验证的工具收据不再以 ok=true 冒充完成；界面显示等待/部分结果的黄色提示。
6. 新会话过快返回的消息不再因会话标识尚未同步而被当成过期消息丢弃。
7. 流式与断线回放共用终态卡去重逻辑；隐藏尚未实现可靠恢复时的误导性“继续未完成项”按钮。
8. 正文支持常用粗体、代码、列表、表格与安全链接。不会因为一句话含“计划”就自动生成执行卡，也不再把“没有已安装项目”涂成成功。

## 先测这 6 件事（无需安装）

1. 选择游戏，发送“mod是什么”：应只有一份回答，粗体正常，不再出现重复长卡。
2. 发送“我害怕，不敢玩，新手什么都不懂，有没有快速适应的方法”：应先回答建议，不自动安装。
3. 发送“帮我搜搜看，最适合我的 mod”：应开始只读搜索；有可信候选才显示清单。没有候选时说明未命中/失败，不能为了展示清单编造项目。
4. 接着说“辅助学习的，界面优化的”：应承接最近搜索需求，不退回泛泛解释或重复整套问卷。
5. 搜索后问“你刚才做了什么？”或说“不用搜了”：应回答/停止，不重新搜索、下载或安装。
6. 有已核验候选时勾选并生成计划：在卡中选择变体；没有确认前不得下载或安装。不需要输入 1A/2B/y/n。

可选：网络不可用时查询，检查是否有明确失败/部分完成结果；恢复网络不会自动续装。
使用真实模型和来源会消耗自己的 API 额度。请不要发送密钥截图或完整配置文件。

## 已验证

- 完整 Python 回归：108 个文件通过（每文件独立进程）。不是 108 次真实模型测试。
- r4 新增 22 个对话/路由/结果用例通过，包含真实 /chat/stream 接口 + 假模型/假来源 + 临时 SQLite。
- 界面摘要去重 15 项、安全 Markdown 渲染 10 项通过。
- 真实 Chromium/React 隔离界面：回答一次 → 搜索清单 → 勾选 → 计划 → 切换具体文件变体 → 确认 → 总结通过；确认请求保留 file_id=102。接口及安装收据是模拟的，没有真实安装。
- 凭据模块 33 项、界面凭据保存契约 8 项，以及后端归属、候选包隔离、任务结果、推荐恢复测试通过。
- Free/P 打包后均通过真实 Windows 加密的假密钥导入、重启解密、后端读取和跳过首次配置页验收。
- 首次回归发现“只检查更新，不要推荐”被停止搜索规则拦住，已修复并复测。
- 人工验证测试原先期待 ok=true，已按真实等待状态改为 ok=false / waiting_user；保持同一文件身份及明确用户处理后的行为测试。

## 未通过验收或仍有限制

- 用户已允许最多 8 次真实模型调用，但独立评测进程无法解密现有 Windows 凭据，实际 API 调用为 0。未改写、删除或替换原凭据；没有真实模型通过率结论。
- 以上界面测试使用模拟接口，不能证明真实网络、所有来源及所有游戏的安装兼容性。
- 路由仍有确定性规则，尚未完成语义分类器接入和多模型漂移评测；未宣称所有口语都可识别。
- 中文查询的英文别名、角色/IP 的精确匹配仍有改进空间；本轮未重写搜索引擎。
- 完整持久化计划授权、崩溃对账、可靠跨重启恢复仍未完成。旧任务恢复继续要求重新核验，不盲目续跑。
- 本轮未验收真实游戏写入、变体共存/卸载所有组合、120 条真实模型三轮重复评测或 500/1000 夜间评测。
- 模型自然语言流仍可能缓冲后展示；代码生成的阶段进度保留，不宣称完整逐 token 输出已恢复。
- 构建有既有 tzdata 缺失、Vite CJS/模块类型警告；未影响本轮打包启动验收。
