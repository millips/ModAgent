# ModAgent Shared Credentials r3 独立测试包

版本：1.6.0-beta.1；构建标识：shared-credentials-20260906-r3。
继承 r2 提示词精简；不代表 Agent Core v2 全部完成。

## 打开哪个

- Free/ModAgentBeta-CoreSafety.exe
- P/ModAgentPBeta-CoreSafety.exe

保留整个 Free/P 文件夹，不要只复制 exe。不覆盖原桌面版、r1 或 r2。
同一 Windows 用户已在旧 ModAgent 配置过密钥时，本包会尝试自动复用；成功后直接进入主界面。
若仍出现配置页：旧密钥可能无法解密、缺少服务地址/模型，或当前测试配置选择了其他地址。请不要发送完整配置或密钥。

## 共享与隔离

- 公共库：%APPDATA%/ModAgent/Credentials/credentials-v2.json，使用 Electron safeStorage / Windows 当前用户加密，不写明文 Key。
- 只共享 LLM/Nexus/Tavily 密钥和对应 LLM 接口地址、模型名。聊天、Mod 清单、快照、授权和会员数据不共享。
- 首次只读导入当前用户 .modagent、.modagent-beta 的 config.json/secrets.json；保留原文件。已有公共库时，不用旧版重新覆盖它。
- LLM 密钥必须有明确服务地址和模型；没有就不猜测其服务商。
- 测试数据：%APPDATA%/ModAgent-TestProfiles/shared-credentials-20260906-r3/free/data 或 subscription/data。
- 测试包修改密钥默认只生成当前测试配置的加密覆盖文件，不改已有公共库；在测试版新增其他密钥也不会回写正式配置。
- 本机完全没有公共凭据时，首次配置可建立公共默认值。之后测试修改保持本地隔离。
- 修改接口地址需要填写对应密钥；仅修改同地址的模型名不需要重填 Key。已有配置主动选过别的地址时，不把公共 Key 自动发过去。
- 旧 r1/r2 不会自动获得新能力，请打开 r3；以后采用新机制的版本才能继续复用。没有跨电脑/跨 Windows 用户同步。
- Windows 加密不隔离同账户下其他本地程序。密钥不回显到页面、不写日志、不打入分发包。
- agent_core_v2 固定 on，应用自动更新关闭。数据隔离不等于游戏目录隔离，写操作仍请使用模拟目录。

## 你可以测试什么

1. 打开 r3：已有可复用配置时直接进入工作区；设置中密钥显示已设置及来源提示，不回显 Key。
2. 退出再打开：无需重复输入。
3. 分别打开 Free/P：新测试配置复用公共默认值，聊天与游戏状态仍隔离。
4. 只修改接口地址、不填新 Key，点击保存：应拒绝并说明原因；原配置仍保留。测试后恢复原地址。
5. 可选测试本地覆盖：在一个测试版填另一份有效 Key，不应改变另一个测试配置或旧版。不要截图密钥。
6. 可选发一句普通问题验证服务连接。这一步会消耗你自己的 API 额度；自动验收没有代你调用付费模型。
