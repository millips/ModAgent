本包是分阶段交付，不是 Agent Core v2 全部完成。流式输出本轮保持不变。

## 打开与隔离

- Free/ModAgentBeta-CoreSafety.exe
- P/ModAgentPBeta-CoreSafety.exe

保留完整文件夹，不要只复制 exe。旧正式版、r4 包及其数据不覆盖，候选包不自动更新。

## 本轮修复

1. GitHub 作者名称不再当作当前游戏证据。精确搜索 SMAPI 等框架时，仅保留官方框架，不混入依赖它的其他 Mod。
2. 推荐规范化统一拒绝明确跨游戏的 Nexus 链接、明确否认其为真实 Mod 的证据及来源无效标记；未核验不等于无效。
3. BepInEx 通用冲突预览与实际安装共用路径规则，不再一边说不支持落位、一边实际可以安装。
4. GitHub/Thunderstore 已选版本带入下载门禁；来源或本机版本不同，需要重新核验，不能换成最新版或误报已经完成。尚不支持自动解析历史版本。
5. 超时会通知正在运行的工具取消。取消权限检查出错时停止。同一后端进程内、同一游戏的写操作串行执行。
6. 文件安装事务中取消会回滚；下载读取中断且没有总长度时保留临时文件，不误报完整下载。实际下载和公共 JSON 请求启用正常证书验证。
7. 新任务持久保留选择和游戏安装实例。“恢复选择并重新核验计划”从服务端取回目标、版本和变体；客户端不能借恢复替换目标或伪造执行确认。
8. 恢复时下拉框同时识别已保存的 variant_id/file_id，不再因为缺少 selected_variant_id 回退到默认款；恢复后不重新选择直接确认，仍提交原文件。

## 已验证的证据（分开统计）

### 确定性回归与界面

- 全量 Python：112 个测试文件分别在独立进程通过。不是 112 次真实模型测试。
- r5 四个新增文件：15 项执行/证据/路径测试、4 项恢复测试、4 项版本测试、1 项真实本机 HTTP 续传测试；另补充 2 项下载证书/残包测试。
- 本机 HTTP 测试真正启动服务器：中途取消保留 .part；新 Python 进程使用 Range 续传，最终哈希一致。
- 新 Python 进程读取 SQLite，恢复同一组选择；API 恢复请求中的恶意替换目标和确认字段被覆盖为服务端原目标、只读计划。
- 真实隐藏 Chromium/React：回答去重 → 推荐表 → 勾选 → 计划 → 变体 → 确认 → 总结 → 恢复选择重新核验 → 再次明确确认，通过。测试同时断言恢复后的下拉值和确认 file_id=102。界面使用模拟 API，不能冒称真实模型全链路。
- Free/P 最终桌面包均通过隐藏启动、后端健康、渲染器无异常、假密钥加密导入、新进程重启读取和跳过首次配置页验收。只使用假密钥，不代表已解决真实跨配置密钥复用。包哈希见交付清单。

## 尚未完成，不能当作已通过

- 完整安装任务的跨重启续跑：还缺持久化逐步执行授权、崩溃对账、跨后端进程写入隔离。当前恢复只重建只读计划，不自动跳过成功项续装。
- 强制结束后台后，历史运行中任务不一定自动转成中断卡；不能保证所有旧任务都有恢复按钮。
- 不同 Nexus 文件/组件共存、跨批次身份与卸载组合仍需治理。此次版本保护不等于变体体系全部修好。
- 中文别名、角色/IP/功能组合精确匹配尚不全面；没有 120 条真实模型准确率结论。
- 本轮未读取或解密真实 API 密钥，未运行真实模型；真实来源测试不等于真实模型决策测试。
- 没有验证真实 Steam 游戏目录、所有来源和所有游戏。网络总预算、重试参数、浏览器链路未全部统一。
- 取消能阻止新增工作并回滚受控事务，但外部不可中断操作可能仍需核验；界面停止不代表全部工作瞬间停止。
- 构建有既有 tzdata、Vite CJS/模块类型警告。

## 你按这个次序测

建议用新建的游戏测试副本，关闭其他 Mod 管理器。本包不自动创建游戏副本。

1. 搜索：明确 Mod 名、功能、一个不确定目标各测一次；看是否属于当前游戏、真正满足目标，而非热门补位。
2. 推荐/计划：选一个前置少、来源已核验的目标。检查依赖归属；有变体就在控件选，不能要求手输编号。
3. 下载/安装：看清路径和风险后确认。最后应说明已装、未装及原因；失败或等待登录不得标成安装完成。
4. 管理：刷新清单，检查名称、来源、版本、文件数。先禁用再启用，在游戏中确认变化；不凭文件放置宣称生效。
5. 卸载：先预览范围再确认。只删目标，不连带误删共享前置和其他组件。需要回滚先看快照影响。
6. 取消/插话：下载中取消，再问“刚才完成了什么？”或发“？”；应该回答，不自动继续旧安装。
7. 恢复：有恢复按钮的失败任务，重开应用后恢复，原目标和变体应保留，先核验再确认。强杀后台后的完整安装续跑暂不列为已完成项目。

反馈请包含游戏、原话、选中项、预期、实际和失败阶段；优先诊断导出，避免密钥截图。
包文件哈希及复制验证见 PACKAGE-MANIFEST.json。源码含保留的未提交修改，不能仅凭 Git 提交号重建。
