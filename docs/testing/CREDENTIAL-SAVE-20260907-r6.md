# ModAgent r6 凭据保存修复：测试任务单

日期：2026-09-07。基础版本：1.6.0-beta.1；补丁：credential-save-r6。

## 开始前

1. 先完全退出旧 r5，再打开本目录 Free 或 P。不要同时开，否则可能激活旧程序。
2. 请选择原来使用的同一版本，截图来自 P 就继续用 P。
3. r6 程序放在独立目录，但有意沿用 r5 测试配置 chain-reliability-r5，尽量复用此前保存的本地密钥。不是全新空白数据，也不是正式版配置。Free/P 测试配置分别保存。
4. 不要删除凭据文件、复制 Local State、发送真实 Key 或为测试破坏自己的配置。

## 修复范围和限制

- 共享密钥文件无法解密，不再阻止测试版本读取自己的本地密钥。
- 本地保存成功后，可选的共享发布失败不再让整个保存报失败，仍可进入主界面并交给后台使用。
- 不把不可读共享文件当空文件覆盖；本地文件不可读仍停止覆盖。
- 文件忙、加密不可用、本地凭据不可读有更明确的中英文说明。

这不是任意版本完全共用 Key 的最终实现：不同加密上下文仍不能直接读取彼此密文。r6 允许本地使用并保留旧文件；新配置没有可读 Key 时仍可能需要输入一次。Free/P 之间也不保证免输入。

搜索、下载安装、管理、卸载复用 r5 后台；本次未改流式输出，也不代表 Agent Core v2 全部验收。
