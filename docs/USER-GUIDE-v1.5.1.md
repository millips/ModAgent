# ModAgent v1.5.1 使用教程

## 安装

- 普通版运行 `ModAgent-Setup-1.5.1.exe`；P 版运行 `ModAgent-P-Setup-1.5.1.exe`。
- 首次启动填写可用的大模型 API；搜索 API 与 Nexus API 可以之后在设置补充。
- 网页登录或人机验证请在 ModAgent 打开的浏览器中自行完成，完成后回到应用继续任务。

## 安全安装 Mod

1. 先阅读候选 Mod 的简介、来源、依赖和风险。
2. 选择目标后生成安装计划；计划会检查已装项、重复、冲突、依赖与适配证据。
3. 只有通过门禁的项目才可安装。BepInEx、SMAPI、MelonLoader 等基础运行环境会单独识别，不会被当作普通 Mod 重复安装。
4. 最终安装仍须用户确认。完成后会刷新 Mod 列表，并清理本轮已使用的下载缓存。

## 导入官方社区合集

1. 首页点击“导入社区合集”。
2. 输入官方六码，例如 `ma-repo-000002`。
3. 查看已安装项、待核验项、缺失依赖、来源与警告。
4. 缺少依赖时先补齐；通过后生成安装计划，再由你确认执行。

官方合集不包含 API Key、Cookie、账号、游戏路径或本地文件内容。

## P Share 投稿（仅 P 版）

1. 在设置完成 P 验证，进入“P Share / 分享者主页”。
2. 在 Mod 管理页选择已对齐来源的 Mod，填写标题、简介和警告并导出投稿 JSON。
3. 打开预填 GitHub 投稿页后提交，再从剪贴板关联 Issue。
4. 审核发布后可在分享者主页复制官方六码。

## 快照与清理

- 快照用于回滚 ModAgent 管理范围内的 Mod 文件，不替代游戏存档备份。
- 使用 `ModAgent-Cleanup-1.5.1.exe` 前先退出应用；清理器只处理经过标记验证的 ModAgent 目录。
- 安装包未进行商业代码签名，可使用 `SHA256SUMS.txt` 核对完整性。
