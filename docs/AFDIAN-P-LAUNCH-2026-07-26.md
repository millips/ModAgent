# ModAgent P 爱发电发布文案

更新时间：2026-07-26

## 项目介绍

ModAgent 是一个 AI 驱动的开放式 Mod 管理助手。用户可以用中文描述需要的 Mod，由 Agent 帮助搜索多个来源、进入详情页核验、整理前置依赖和风险，并在用户确认后生成安装计划。

普通版已经保留完整的搜索、核验、推荐、安装、更新、卸载、快照和配置补丁能力。ModAgent P 不把这些核心功能上锁，只提供更完整的视听和身份体验。

## P 专属权益

- P 专属主题；
- P 专属音效；
- P 视觉动效与反馈核心；
- P 专属程序图标和身份标识。

## 开业体验规则

- P 包首次启动自动开放 3 天试用；
- 本档位发放一枚 60 天 P 兑换码；
- 兑换码一次输入后保存在本机，无需每次输入；
- 到期只关闭 P 专属外观、音效和反馈，不删除数据、不锁普通功能；
- 首发采用离线签名验证，不承诺绝对防破解、联网撤销或设备数量限制；
- 后续联网验证上线时，会员验证入口和既有数据不会因此重做。

## 获取和安装

1. 下载爱发电私密文章中的 `ModAgent-P-Setup-1.3.0.exe`。
2. 对照文章内 SHA256 校验文件。
3. 安装并启动 ModAgent P。
4. 进入“设置 → ModAgent P · 会员验证”。
5. 粘贴 Bot 发放的兑换码并点击“验证”。
6. 页面显示剩余天数和到期时间即激活成功。

新版本发布时，重新下载同渠道的新安装包并覆盖安装。默认保留 `.modagent` 数据、配置和 `license.dat`。

## 首次使用

ModAgent 只强制要求一个大模型 API Key。DeepSeek 为默认推荐，也支持 OpenAI-compatible 接口。Nexus Mods 和 Tavily API Key 是可选增强，可以跳过后在设置中补充。

## 必须了解

- 当前安装包尚未购买商业代码签名证书，Windows 可能显示“未知发布者”；
- ModAgent 不绕过第三方平台登录、人机验证、付费或作者权限；
- 详情已核验不等于 Mod 组合已经实机兼容；
- 未专项适配的游戏会显示通用安装风险；
- 安装前请备份存档和重要游戏文件；
- 请勿在反馈中发送 API Key、Cookie、账号密码或未脱敏日志。
