# ModAgent P v1.5 发布说明

## 这次更新了什么

v1.5 把“分享一套可复现 Mod 配置”的完整链路带进了 ModAgent。

- **P Share 创作者投稿**：P 用户可从已对齐的本机 Mod 中选择内容，填写标题、简介、警告后导出投稿 JSON，并通过 GitHub 官方投稿页提交。
- **分享者主页**：查看投稿、关联 GitHub Issue、同步审核状态；审核通过后获得官方六码，例如 `ma-repo-000002`。
- **官方社区合集导入**：任何用户输入官方代码后，先看到本机已装项、缺失项、依赖、冲突与警告，再生成安装计划；不会直接自动安装。
- **尊重创作者来源**：合集保存上游页面和依赖证据，安装仍从原平台/作者页面获取，不转载 Mod 文件。

## P 专属权益

- P 专属主题、音效、视觉动效与反馈；
- P 专属图标和身份标识；
- P Share 创作者投稿、分享者主页与官方投稿辅助流程。

普通版同样可使用搜索、核验、安装计划、本地 Mod 管理、快照，以及导入已审核的官方社区合集；P Share 的“创建并投稿官方合集”仅向有效 P 用户开放。

## 使用方式

1. 下载并运行 `ModAgent-P-Setup-1.5.0.exe`。
2. 在设置中输入兑换码，激活 P 身份。
3. 到 Mod 管理页完成来源对齐，选择要分享的 Mod。
4. 打开 P Share，导出并提交投稿；审核通过后即可向朋友发布官方六码。

## 说明

- P 授权为本地离线签名验证；P 包首次启动提供试用，兑换码有效期以页面显示为准。
- 会员到期只影响 P 专属体验与 P Share 投稿，不删除 Mod、快照、配置或普通功能。
- 官方审核不收录侵权转载、限制级/违法内容、隐私或密钥、恶意指令、来源不明或误导性投稿。
- 安装包尚未进行商业代码签名；请以 `SHA256SUMS.txt` 核对文件完整性。
