# ModAgent P 会员与兑换码教程

## 权益范围

P 只锁定四项：专属主题、专属音效、视觉动效与反馈核心、专属图标和身份标识。搜索、核验、依赖、安装、更新、卸载、快照、配置补丁和数据导出不属于 P 专属。

## 三天试用

P 包第一次启动时建立本机试用记录并开放 3 天。重新启动或覆盖安装不会重置试用。明显回拨系统时间会触发保护提示。

## 激活 60 天兑换码

1. 打开“设置”。
2. 找到“ModAgent P · 会员验证”。
3. 粘贴爱发电 Bot 发放的完整兑换码。
4. 点击“验证”。
5. 核对剩余天数、到期时间和 License ID。

兑换码由签发私钥进行 Ed25519 签名。安装包只包含公钥，因此修改 `license.dat` 或随意编造字符串不能生成有效兑换码。

## 保存位置

授权状态保存在 `.modagent/editions/subscription/license.dat`，内容使用 Electron `safeStorage` 调用 Windows 加密存储保护。不要手动编辑该文件。

## 到期后

到期后 P 专属外观、音效和反馈锁定，界面恢复基础外观；普通功能和用户数据继续可用。输入新的有效兑换码即可恢复 P 权益。

## 重装与更新

覆盖安装默认保留 `.modagent`，所以无需重新输入。若使用一键清理器主动删除稳定版 `.modagent`，许可证也会被删除，且不可恢复；此时需要重新使用原兑换码。相同兑换码保留其原激活时间，不会重置 60 天。

## 常见问题

- **提示签名无效**：确认兑换码复制完整，没有多余字符。
- **提示许可证文件无法读取**：确认 Windows 加密存储可用；不要从另一台电脑直接复制 `license.dat`。
- **提示系统时间异常**：启用 Windows 自动校时后重启。
- **安装包泄露怎么办**：没有有效兑换码时只可使用 3 天试用，之后只剩普通功能；首发离线方案无法远程封禁已经签发的码。
- **能否保证不被破解**：不能。首发目标是阻止简单复制和伪造，联网设备验证与撤销将在后续版本增加。
