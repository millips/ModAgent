# ModAgent v1.5.1 发行安全审查

审查日期：2026-08-02

## 结论

v1.5.1 是 v1.5 稳定线修复发布。普通版与 P 版均包含搜索、核验、安装计划、本地 Mod 管理、快照和官方社区合集导入；P 版额外提供 P 视觉权益与 P Share 投稿能力。

## 本次修复

- 识别本机已安装的 BepInEx、SMAPI、MelonLoader 等基础运行环境，不再误报为普通依赖缺失。
- 官方合集只在真正缺失依赖时阻止生成安装计划。
- 已发布 P 投稿可显示和复制官方分享六码。
- Thunderstore 已知游戏社区优先直连，并在临时失败时进行受控重试和目录缓存回退。

## 安全边界与限制

- 官方合集不保存 API Key、Cookie、账号、绝对游戏路径或第三方 Mod 文件本体。
- 导入只预览与核验；安装必须由用户确认。
- 文件写入、卸载、快照和清理受游戏根目录或 ModAgent 标记目录约束。
- 安装包未进行商业代码签名；第三方站点的登录、人机验证、网络连接和 Mod 本体兼容性不由 ModAgent 控制。
- 快照更细的批量合并策略将在后续 v1.5.x 维护更新中继续优化。

## 发布门槛

- [x] 分享配置、依赖环境识别和安装门禁测试通过。
- [x] 普通版与 P 版构建身份、资源隔离和启动烟雾测试通过。
- [x] 两版生成 SHA-256 校验值。
