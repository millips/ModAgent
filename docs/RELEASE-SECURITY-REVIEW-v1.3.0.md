# ModAgent v1.3.0 发行安全审查

审查日期：2026-07-26

## 结论

v1.3.0 可以作为未签名的首发候选进入最终实机核验。P 权益边界已限制为表现层，授权失败或到期不会阻断核心 Mod 管理或删除数据。仍需在正式上传前完成安装包烟雾测试、SHA256 固化和私钥备份。

## 已实施

- 普通版和 P 版使用独立产品名、图标、可执行文件名与更新清单；
- P 兑换码使用 Ed25519 签名，客户端只包含公钥；
- 签发私钥保存在仓库外，不进入安装包；
- `license.dat` 使用 Windows 加密存储；
- 3 天试用记录不随普通重启或覆盖安装重置；
- 检测超过 6 小时的明显时间回拨；
- P 到期只关闭主题、音效、视觉动效/反馈和身份表现；
- 普通版打包检查拒绝 P 主题、音频、公钥和 P 图标；
- 外部链接采用受信主机白名单；
- 更新清单限制 HTTPS、重定向次数、响应大小和超时；
- 卸载默认保留稳定数据，一键清理器对自选目录进行双文件标记验证；
- 日志、配置、缓存和诊断入口已集中到设置页。

## 已知风险

1. **未做 Windows 代码签名**：SmartScreen 可能警告，用户无法通过发布者证书确认来源。
2. **离线授权可被逆向绕过**：本地验签不能保证绝对防破解。
3. **离线码不能远程撤销**：码泄露后只能在后续联网版本处理。
4. **本机时间依赖**：已阻止明显回拨，但不能替代可信服务端时间。
5. **P 包可被转发**：转发者仍可获得 3 天试用；没有有效码时不能持续使用 P 表现层权益。
6. **离线码可被共享**：v1.3.0 不绑定设备，同一有效兑换码可在多台电脑输入；这属于首发“君子锁”的明确限制。
7. **第三方站点风险**：网页内容、下载包和 Mod 兼容性不受 ModAgent 控制。
8. **自备 API Key**：Key 安全仍依赖用户账户、服务商政策和本机安全。

## 发布前硬性检查

- [ ] 普通版首次配置只要求一个 LLM Key，Nexus/Tavily 可空；
- [ ] P 版无兑换码可试用，试用结束后四类权益锁定；
- [ ] 有效 60 天码可激活并显示正确到期时间；
- [ ] 普通版包不含 P 音频、主题、公钥和 P 图标；
- [ ] P 包包含正确公钥与 `ModAgentP.exe`；
- [ ] 普通版/P 版安装、覆盖安装、卸载、彻底清理均实测；
- [ ] 普通版和 P 版均完成游戏扫描、手动导入、搜索、详情核验、安装与快照基本链路；
- [ ] 安装包、便携包、清理工具均生成 SHA256；
- [ ] GitHub 只公开普通版和更新清单，不公开 P 安装包；
- [ ] 爱发电私有文章提供 P 包、SHA256、教程和兑换码；
- [ ] 签发私钥至少保存两份离线备份，不上传网盘公开链接、GitHub、聊天或安装包。

## 致命缺陷响应

发现会损坏游戏文件、泄露密钥或导致不可逆数据丢失的问题时：

1. 立即暂停 GitHub/蓝奏云/爱发电下载；
2. 更新清单把 `severity` 设为 `critical`，填写最低安全版本与停止使用说明；
3. 发布公告，给出受影响版本、临时规避和数据恢复方法；
4. 修复后重新构建、运行完整烟雾测试并生成新的 SHA256；
5. 使用相同渠道提供覆盖安装包；
6. 保留事故记录和根因分析，不静默替换文件而不变更校验值。
