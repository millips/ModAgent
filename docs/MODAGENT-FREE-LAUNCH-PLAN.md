# ModAgent 普通版 GitHub 发布与推广规划

版本：v1.0.0
主阵地：GitHub Releases
目标：先获得一批愿意反馈真实安装问题的 Windows Mod 玩家，再逐步扩大传播。

## 一、发布定位

一句话定位：

> 用对话完成 Mod 搜索与方案分析，用快照把本地文件操作留在可回滚范围内。

核心受众：

- 同时管理多个游戏 Mod、经常忘记安装位置或依赖关系的玩家
- 想用自然语言搜索 Mod，但仍希望在执行前亲自确认的玩家
- 愿意测试早期 Windows 工具并提交反馈的 GitHub、Bilibili、贴吧和 Mod 社区用户

暂不承诺：

- 不承诺绕过 Nexus Mods 登录、人机验证或平台下载限制
- 不承诺所有游戏都能自动识别安装规则
- 不使用“全自动、零风险、一键兼容所有游戏”等绝对化表述

## 三、首发文案

### 长版

找 Mod、看说明、确认版本、解压到目录、出问题后再手动排查——这些步骤通常分散在网页和文件夹里。

ModAgent 普通版把它们整理进一个 Windows 桌面界面：你可以用自然语言描述想找的 Mod，让它搜索并分析候选；执行前仍由你确认；安装后的本地 Mod 可以统一查看；关键文件操作可配合快照和回滚处理。

v1.0.0 现在开放测试。它不是“绕过平台限制的一键下载器”：Nexus Mods 出现登录、人机验证或 Slow download 页面时，仍需要用户完成平台要求的操作。对于未特化适配的游戏，也需要认真核对安装位置和文件清单。

如果你愿意帮助测试，欢迎下载普通版并在 GitHub Issues 提交游戏名称、复现步骤和脱敏日志。

### 中版

ModAgent 是一款 Windows 本地 AI Mod 管理器，提供对话搜索与分析、游戏识别、Mod 管理、安装前确认、快照和回滚。v1.0.0 普通版现已开放测试。

Nexus Mods 的登录、人机验证和 Slow download 仍遵循平台流程；未适配游戏请在执行前核对文件位置。欢迎通过 GitHub Issues 反馈真实使用问题。

### 短版

ModAgent 普通版开放测试：对话找 Mod、分析候选、统一管理，并用快照降低文件操作出错后的恢复成本。Windows 用户可在 GitHub 下载。

## 五、渠道与节奏

### D-3 至 D-1：预热

- GitHub 仓库补齐简介、功能截图、安装须知和 Issue 模板
- 发布 10–20 秒无旁白界面录屏，结尾只放发布日期与仓库地址
- 邀请 5–10 名已知测试者覆盖不同游戏和 Windows 环境

### D0：首发

- 创建 GitHub Release，上传安装包、便携包、校验值
- 同步发布 Bilibili 动态/视频、贴吧或对应游戏社区长帖
- 所有渠道统一引导到 GitHub Release 下载和 Issues 反馈

### D1 至 D7：公测响应

- 每天汇总一次：启动失败、游戏识别、下载接管、安装位置、回滚
- 高影响问题使用 GitHub Issue 置顶，避免重复反馈
- 第 3 天发布“已知问题与解决办法”
- 第 7 天发布首周数据与修复计划

### 第二周以后

- 按游戏制作真实案例，而不是重复发产品总览
- 每个案例只突出一个问题：找不到 Mod、依赖难理清、卸载难恢复等
- 普通版保持开放核心能力；Pro 只介绍确实存在且稳定的增强体验

## 六、首发视频脚本（45–60 秒）

1. 0–5 秒：网页和文件夹快速切换，字幕“装一个 Mod，为什么要开这么多页面？”
2. 5–15 秒：打开 ModAgent，对话输入一个明确需求。
3. 15–28 秒：展示搜索结果和方案分析，强调“先分析，再决定”。
4. 28–40 秒：切到 Mod 管理页，展示启用、禁用或卸载入口。
5. 40–50 秒：切到快照页，展示恢复点和回滚入口。
6. 50–60 秒：显示 GitHub 地址，字幕“普通版 v1.0.0 开放测试｜Windows”。

旁白核心句：

> ModAgent 不替你跳过平台验证，也不替你盲目确认；它负责把信息和步骤整理好，把最后决定留给你。

## 七、转化与反馈指标

首月重点不看曝光总量，优先看：

- Release 页面访问到下载的转化率
- 成功启动并完成首次配置的比例
- 至少完成一次游戏识别、Mod 扫描或快照的用户数
- 有完整复现步骤的有效 Issue 数
- 启动、下载、安装、回滚四类问题的失败率

建议首月目标：

- 100–300 次有效下载
- 20 名完成核心流程的测试用户
- 10 条以上可复现反馈
- 关键数据丢失问题为 0

## 九、普通版与 Pro 的传播边界

普通版可以宣传：

- 对话搜索与方案分析
- 游戏识别和手动导入
- Mod 扫描与本地管理
- 操作前确认
- 快照、预览和回滚

Pro 单独宣传：

- 可交互的推荐勾选表与确认页联动
- 订阅视觉主题、动效与反馈体验
- 以后经验证稳定的订阅增强功能

两版共同遵守：

- 不绕过第三方平台验证
- 不隐藏真实失败状态
- 不在重新生成回答时重复执行已经完成的文件操作
