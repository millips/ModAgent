# ModAgent Feedback Lab

独立的声音与动效反馈实验室，不连接 ModAgent 后端，也不会修改正式界面。

## 启动

在 `electron` 目录执行：

```powershell
npm.cmd run lab
```

默认读取 `%USERPROFILE%\Desktop\音频素材`，也可以用“添加素材”临时导入其他音频。

## 当前能力

- 素材试听、搜索和临时导入
- 按事件保存独立声音组合，并覆盖警告、失败、危险确认、撤销、启停、扫描和批量完成
- 每层延迟与音量控制
- 总音量、播放速率和随机变调
- 动效时长、按压深度、辉光与粒子数量
- 精密、沉重、弹性、脉冲四种手感预设
- 浏览器本地保存实验方案，同时导出可检查的 JSON

后续可以继续加入波形裁切、包络、均衡器、压缩器、动效曲线编辑和主题包导出。
