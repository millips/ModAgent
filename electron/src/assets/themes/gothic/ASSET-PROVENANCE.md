# Gothic Cathedral theme asset provenance

All raster assets in this directory were generated specifically for ModAgent
Pro on 2026-07-21 with OpenAI's built-in image generation tool. They are not
copied from a third-party game, brand, artist, cathedral photograph, or asset
pack.

- `background/cathedral-nave-v1.png`: original midnight neo-gothic cathedral
  wallpaper with a central rose window and dark UI-safe side regions.
- `core/rose-window-core-v1.png`: circular stained-glass feedback core, chroma
  keyed from `sources/rose-window-core-chroma-v1.png`.
- `ornaments/raven-candle-v1.png`: medium/tall settings-card ornament, chroma
  keyed from `sources/raven-candle-chroma-v1.png`.
- `ornaments/thorn-fleur-v1.png`: short navigation ornament, chroma keyed from
  `sources/thorn-fleur-chroma-v1.png`.
- `ornaments/altar-wide-v1.png`: wide recommendation-header ornament, chroma
  keyed from `sources/altar-wide-chroma-v1.png`.

Each ornament has one assigned size class and one primary UI placement. The
application must preserve aspect ratio and must not use these files as
stretched panel backgrounds. Panel geometry, borders, arches and responsive
behavior remain code-native.
