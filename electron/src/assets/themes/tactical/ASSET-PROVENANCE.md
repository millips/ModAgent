# Tactical Armory theme asset provenance

All raster assets in this directory were generated specifically for ModAgent
Pro on 2026-07-21 with OpenAI's built-in image generation tool. They are not
copied from a real firearm manufacturer, military organization, game, artist,
or asset pack. All depicted weapons and accessories are fictional and
unbranded.

- `background/armory-workshop-v1.png`: original near-future private armory and
  engineering-workshop wallpaper.
- `core/optic-core-v1.png`: circular fictional optical-sight feedback core,
  chroma keyed from `sources/optic-core-chroma-v1.png`.
- `ornaments/rail-module-v1.png`: short active-navigation ornament, chroma
  keyed from `sources/rail-module-chroma-v1.png`.
- `ornaments/carbine-stand-v1.png`: medium/tall settings-card ornament, chroma
  keyed from `sources/carbine-stand-chroma-v1.png`.
- `ornaments/workbench-wide-v1.png`: wide recommendation-header ornament,
  chroma keyed from `sources/workbench-wide-chroma-v1.png`.

Each ornament has one assigned size class and one primary UI placement. Aspect
ratio must be preserved. Armor panels, cut corners, status marks, reticles and
responsive container geometry remain code-native rather than stretched raster
skins.
